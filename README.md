# AI Chatbot 🤖💬

An intelligent, responsive web-based virtual assistant integrated with the **Google Gemini AI API** to provide human-like conversational experiences.

## ✨ Features
- **Generative AI Integration:** Communicates using Google Gemini's powerful LLM backend.
- **Responsive Design:** Optimized layout for seamless use across mobile and desktop browsers.
- **Clean UI:** Minimalist chat interface with real-time text rendering.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **API:** Google Gemini AI API
